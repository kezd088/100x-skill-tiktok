# 失败门禁

| 门禁 | 失败模式 | 当前处理 |
|---|---|---|
| 源文件不可变 | 抽帧或转码覆盖原片 | 只读输入，输出到新目录并记录 SHA-256 |
| 切点不是事实 | 单阈值场景检测漏短镜或过度切分 | 双阈值加均匀采样；检测结果只作提议，人工/多模态校正 |
| 默认视频采样不足 | 快速手势、商品动作、闪切被模型默认采样漏掉 | 完整视频与本地稠密帧、音轨同时分析 |
| 文字和商业事实 | OCR/听写误差被补成品牌、价格、功效 | 仅逐字记录可见/可听内容；其余留空并降低置信度 |
| 资产连续性 | 人物、商品、服装和场景跨镜头漂移 | 稳定资产 ID、截图、锚点和 `must_not_change` |
| 旧媒体误复用 | 反馈后时间戳已变，但同路径非空截图被直接跳过 | 物化 provenance 绑定源哈希、请求时间戳和文件哈希；不匹配即换新目录 |
| 片段长度 | 为适配模型机械每 10 秒硬切 | 沿真实镜头/叙事边界分段；长度只产生兼容警告 |
| 外部上传 | 服务要求公网 URL 后擅自发布原片 | 无明确授权即停止该路线，不上传、不创建公开链接 |
| 模型能力 | 猜测模型 ID 或把同名模型当官方能力 | 调用前查官方模型列表和文档；不可用时保留原始错误并停止替换 |
| 生成方案 | 未核实模型和输入能力却标为“可执行” | 每段 execution_plan 显式区分 ready / needs_model_selection / blocked；ready 必须带真实模型、方式、输入和核验时间 |
| 可视化缺层 | 只交付 JSON 路径或一段汇总提示词，用户看不到源片、分镜和资产 | 当前对话展示源片入口、全部分镜三帧、资产库和逐段生成方案 |
| 原生输出失真 | 回复内容与已验证 `reverse.json` 不一致，或引用临时／过期媒体 | 回复只从当前包投影；显示绝对路径前确认它仍对应包内已验证媒体 |
| 可视化遮错 | 回复隐藏缺图、警告、不确定项或未选模型 | 在对应镜头、资产或分段原位显示真实状态；缺失交付媒体为硬错误 |
| 成本 | 为验证反推包自动开始付费生成 | 本 Skill 零生成调用；成本和生成由下游独立授权 |
| 重试 | 安全/隐私拒绝后无限重试 | 本 Skill 不处理生成重试；下游同一失败最多一次，随后保留证据 |
| 分数混写 | 反推包高分被当作最终复现高分 | 分开报告；金样反推 92.00，冠军生成路线仅 49.40 |
| 许可证 | 复制无 License 或冲突 License 候选代码 | 只吸收抽象方法，不复制实现；来源和边界写入黄金基线 |
| Schema 运行库 | 缺少 `jsonschema` 时浅层 fallback 把坏包判为通过 | 缺库直接作为硬错误；只在隔离环境安装后重验 |
| 空心结构包 | 字段类型和路径齐全，但提示词、动作、镜头语言与叙事内容为空 | Schema `minLength/minItems` 加语义门禁；不存在时写明确的“未观察到”，不可留空或编造 |

## 硬停止条件

- 输入不是可读视频，或源文件在运行中发生哈希变化。
- 输出目录包含既有文件，可能覆盖用户结果。
- `ffmpeg` / `ffprobe` 不可用，且无法建立本地证据。
- Python `jsonschema` 不可用，无法完成完整契约验证。
- 外部调用需要上传或付费，但当前请求没有明确授权。
- 指定模型的真实 ID、输入能力或官方入口无法核实。
- 验证器出现硬错误：缺字段、时间轴断裂/重叠、未知资产引用、缺失媒体或未替换占位符。
- 新包缺少逐段 `execution_plan`，或 `ready` 状态缺少真实模型、输入素材和核验时间。

## 需显式交接的警告

- 建议分段超过当前下游时长上限。
- 极短镜头、高运动模糊、遮挡、反光或压缩导致低置信度。
- 无音轨、听写来源不可靠、烧录字幕与音频不一致。
- 资产只在极少帧出现，无法建立稳定锚点。
- 当前供应商限制可能在未来变化，尚未实时复核。
