# Agent 原生输出契约

默认交付发生在当前 Codex、Claude Code、WorkBuddy／CodeBuddy 或其他兼容 Agent 对话中。`reverse.json` 和包内媒体是持久真源；对话回复是它们的可视化投影，不额外生成重复报告。

用户只需要表达正向任务，例如“反推这个视频”。默认回复只呈现结果，不解释内部模式选择或历史实现。

## 客户端适配

- 优先使用当前客户端的本地媒体能力展示源视频和图片，不把本地素材上传到公网。
- 图片优先用绝对本地路径内联；客户端不能内联图片时使用其可点击本地预览。视频支持内联时直接播放，不支持时给出可点击绝对路径。
- 客户端不能内联视频时，仍须展示全部分镜三帧和资产图；只有客户端本身不能内联图片时才退化为逐项可点击预览，不能只返回一组无说明的文件路径。
- 只展示包内已验证媒体，不引用临时抽帧、过期修订或公网镜像冒充交付素材。
- 长提示词用代码块；结构、状态、时长和模型用紧凑 Markdown 表格。不要倾倒完整 JSON、哈希清单或内部 provenance。

## 固定信息顺序

1. **结果与源片**：验证状态、镜头／资产／分段数量、警告数；展示源视频或可点击的本地视频入口。
2. **分镜表**：按时间顺序覆盖全部镜头。每个镜头显示 `shot_id`、起止时间、时长、景别／运镜、动作、叙事功能、文字／口播、资产 ID，并在同一块中展示首帧、高光帧和尾帧。不能只给图片路径或代表帧。
3. **资产库**：按人物、产品、场景、道具、服装、音频、文字分组。每项显示资产图／可播放音频、可观察事实、一致性锚点、禁止变化项、通用提示词和已有的模型适配提示词。
4. **生成方案**：先用表格列出每段镜头、源时长、目标时长、状态、真实模型或“未选定”、生成方式和输入素材；随后按分段给出完整提示词。`needs_model_selection` 和 `blocked` 不得写成可执行。
5. **叙事与约束**：展示 Hook、产品桥接、证明过程、CTA、全局提示词、负向约束、必须保持、拼接／后期、限制和不确定项。
6. **成本与耗时**：分别报告本次已发生的外部分析调用成本、生成成本和本地处理耗时。未知写“未取得计量数据”；本 Skill 没有调用生成模型时写“生成成本 0”，不能把订阅价格或估算冒充实际账单。
7. **机器包**：最后给出 `reverse.json`、`validation.json` 和包根目录的可点击绝对路径，供下游 Skill 接力。

## 控制回复体积

- 第一层必须让用户不打开文件也能看懂完整反推结果，但不复述内部 Schema。
- 分镜三帧、资产图和生成方案不能省略；重复观察事实可以合并，长提示词只出现一次。
- 镜头很多时按连续镜头分批分区，不牺牲时间顺序或媒体预览。客户端有单次响应上限时，先交付结果、源片和完整分镜，再在同一任务的后续消息继续资产与提示词，并明确“第 N／M 部分”。
- 用户只要求局部镜头或审计时，只展示范围内内容，并明确这是局部视图。
