# 100x-video-reverse · 来源与替换记录

## 当前能力

公开包 v2.2 延续已验证的视频反推与严格校验能力，并把默认交付收敛为由 `digest.py` 确定性生成的 Agent 对话内可视化。当前能力由五部分组成：

1. FFmpeg／FFprobe 本地只读证据提取。
2. 完整视频、稠密帧和音轨联合的多模态语义校正。
3. 稳定资产 ID、一致性锚点和生成提示词包。
4. JSON Schema、媒体物化、源哈希和 provenance 严格验证。
5. 从同一份 `reverse.json` 投影窄幅竖屏播放器、多列镜头帧板、镜头所属分段提示词、资产和逐段生成方案；多包使用轻量总览加独立详情。

## 版本替换

- 当前版本：`100x-video-reverse@2.2.0`。
- 被替换版本：`2.1.0`，可恢复提交为 `707665921dd630f9913f0886a898f5488a5e1a28`。
- 替换原因：`2.1.0` 规定了对话内可视化内容，但仍由 Agent 手工组织；真实 9:16 素材出现播放器舞台过宽、帧板空间不足，以及镜头和分段提示词之间缺少直接交互的问题。
- 兼容性：`2.2.0` 不修改 v2.1 机器 Schema 或 `execution_plan`。新增的 `digest.py` 同时读取 v2.1 `execution_plan` 和新版运行包的 `recommendation`，展示层可删除、可再生，不回写机器事实。
