# 100x-video-reverse · 来源与替换记录

## 当前能力

公开包 v2.1 延续已验证的视频反推与严格校验能力，并把默认交付改为 Agent 对话内可视化。当前能力由五部分组成：

1. FFmpeg／FFprobe 本地只读证据提取。
2. 完整视频、稠密帧和音轨联合的多模态语义校正。
3. 稳定资产 ID、一致性锚点和生成提示词包。
4. JSON Schema、媒体物化、源哈希和 provenance 严格验证。
5. 从同一份 `reverse.json` 投影源视频入口、分镜三帧、资产、提示词、逐段生成方案、成本与耗时。

## 版本替换

- 当前版本：`100x-video-reverse@2.1.0`。
- 被替换版本：`2.0.0`，可恢复提交为 `6e1c64a27f868f4b1ff57f27bf60d6f154846f4d`。
- 替换原因：`2.0.0` 只保证机器包可交接，没有把源视频、分镜三帧、资产和生成方案规定为当前对话中的默认用户输出。
- 兼容性：`2.1.0` 保留 `2.0.0` 的机器字段，并为新包增加逐段 `execution_plan`。历史包可以审计，但不能在缺少执行方案时显示为当前可执行。
